# 验收清单 — dsh-session-time-bucket

逻辑层（分桶边界、可见性过滤、前缀格式、相对时间、空桶隐藏、核心视图跟随判定、zh/en、bundle 契约）由 `test/bundle.test.mjs`（10 条）自动覆盖。标 `[B]` 的必须人眼看。

## 0. 前置

```bash
cd <dsh-plugins 仓库根>
dsh plugin --profile web install
```

- [ ] 0.1 `[B]` 重启/强刷后，Console 无报错；核心侧栏一切如常（**没有任何额外入口图标**——本插件无独立入口）
- [ ] 0.2 `[B]` 核心“视图选项”菜单 = 核心原生内容（分组方式/排序方式），**无任何插件注入项**

## 1. 跟随激活（单列表 + 最近更新）

- [ ] 1.1 `[B]` 核心分组方式选「单列表」、排序方式选「最近更新」→ 自动激活：核心列表区域被替换为时间桶列表；核心**头部保留**（视图选项、搜索、＋新建仍在原位可点）
- [ ] 1.2 `[B]` 列表：今天/昨天/前7天/前30天/更早（**空桶不出现**）；组标题带 ▾/▸ 与数量，hover 有底色，点击折叠/展开且刷新后保持
- [ ] 1.3 `[B]` 行**恒**显示工作区前缀：`[工作区名] 标题`、未分组 `[未分组]`；行尾相对时间（如 “5天前”）；已归档/子代理不出现；当前空白“新会话”出现在它自己的桶
- [ ] 1.4 `[B]` **进行中**（running）会话行最左有蓝色追逐状态点（与核心一致，动画）；**已完成**（completed）会话行最左有绿色圆点；空闲行无点
- [ ] 1.5 `[B]` 悬停会话行约 0.5s → 行右侧弹出提示卡片：**完整标题**（不截断）+ 相对时间 + 状态（进行中/已完成/空闲，带状态点）；卡片可停留，移出关闭；滚动时跟随
- [ ] 1.6 `[B]` 点行打开会话（高亮随 current）

## 2. 退出 / 还原

- [ ] 2.2 `[B]` 分组方式切回「按工作区」→ 自动退出，核心列表原样恢复

- [ ] 2.4 `[B]` 窄栏（rail）下不激活，核心正常渲染
