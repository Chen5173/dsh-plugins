# 验收清单 — dsh-session-time-bucket

逻辑层（分桶边界、可见性过滤、前缀格式、行身份匹配、桶区间规划、相对时间、核心视图跟随判定、zh/en、bundle 契约）由 `test/bundle.test.mjs`（14 条）自动覆盖。标 `[B]` 的必须人眼看。

架构重点：**不重绘官方列表**。行（状态点、悬停卡、`…` 菜单、拖拽、打开）全部是核心原生元素，插件只注入组头 + 行内工作区前缀。

## 0. 前置

```bash
cd <dsh-plugins 仓库根>
dsh plugin --profile web install
```

- [ ] 0.1 `[B]` 重启/强刷后，Console 无报错；核心侧栏一切如常（**没有任何额外入口图标**——本插件无独立入口）
- [ ] 0.2 `[B]` 核心“视图选项”菜单 = 核心原生内容（分组方式/排序方式），**无任何插件注入项**

## 1. 跟随激活（单列表 + 最近更新）

- [ ] 1.1 `[B]` 核心分组方式选「单列表」、排序方式选「最近更新」→ 自动激活：**列表本身仍是核心原样渲染**（不闪、不替换），行间/行内出现注入元素
- [ ] 1.2 `[B]` 组头：今天/昨天/前7天/前30天/更早（**空桶不出现**）出现在每桶首行上方；▾/▸ + 数量；hover 有底色；点击折叠（该桶行全部隐藏）/展开；刷新后折叠态保持
- [ ] 1.3 `[B]` 每行标题前有工作区前缀 `[工作区名] 标题` / `[未分组] 标题`（12px tertiary，不遮挡截断）；当前空白“新会话”行无前缀；已归档/子代理不出现（核心行为）
- [ ] 1.4 `[B]` 核心原生行为全保留：进行中蓝色追逐状态点、已完成绿点、悬停 0.5s 提示卡、行尾 `…` 菜单（重命名/分叉/归档）、点行打开、拖拽排序——与未激活时完全一致
- [ ] 1.5 `[B]` 进行中会话的 updatedAt 持续变化（行重排）时：组头始终跟随正确的桶边界行（观察者即时重锚，无明显错位/闪烁）

- [ ] 2.2 `[B]` 分组方式切回「按工作区」→ 自动退出，核心树原样
