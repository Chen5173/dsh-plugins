# dsh-session-time-bucket

给 DSH Web GUI **侧栏会话/工作区区**加一种分组：**按时间桶**（今天 / 昨天 / 前7天 / 前30天 / 更早，按会话**最近更新时间**、本地自然日分桶）。

采用**独立入口 + 自绘弹层**的架构（不改核心、**不注入核心的“分组方式”菜单**——该菜单在真实运行时无法安全扩展，见知识库篇目）：在核心“视图选项”按钮旁放一个自己的时钟入口，点开的是插件自绘的弹层（与草图一致：分组方式 → `按时间桶`，勾选后出现横线 + `显示工作区`）。

纯客户端插件。不注册宿主端点、不新增模型工具；数据来自核心 `sessions` / `workspaces` 两个客户端服务，点开会话走 `sessions.open(id)`，新建走 `sessions.create`。

## 行为

| 情况 | 表现 |
| --- | --- |
| 宽态 | 核心“视图选项”图标旁多一个时钟入口（仅宽侧栏） |
| 点时钟入口 | 打开自绘弹层：`分组方式` → `按时间桶`；勾选后出现横线与 `显示工作区` 勾选行；下方提示“勾选后点击空白处生效” |
| 勾选后点空白 / Esc | 激活时间桶模式：核心这一节的头部与列表被**接管**（隐藏），替换为插件界面 |
| 插件界面 | 迷你头部：时钟入口 · `按时间桶` · `显示工作区` 勾选 · `＋新建会话` · `×退出`；下面是时间桶列表 |
| 时间桶列表 | 全部工作区 + 未分组会话混合，按 `updatedAt` 落桶；桶内最新在前；**空桶隐藏**；组标题带 chevron（▾/▸）+ 数量、可折叠并记住折叠态 |
| 会话行 | 行尾显示相对时间（如 “5天前”）；`显示工作区` 开 → `[工作区名] 标题`、无工作区 `[未分组]`，关 → 纯标题 |
| 可见性 | 与核心一致：排除子代理起源与已归档；当前空白“新会话”显示在它自己的桶 |
| 点某一行 | `sessions.open(id)` 打开该会话 |
| 激活后再点时钟入口 | 弹层显示 `按时间桶` 已选中 + `显示工作区`（可实时切换）；**取消勾选即退出**回核心 |
| `＋新建` | 跟随当前会话所在工作区创建并自动打开；无当前工作区则宿主默认 |
| `×退出` | 恢复核心头部与列表；弹层中的选中态同步消失 |
| 刷新 / 重开 | 记住 模式开/关、`显示工作区`、折叠态；上次开着则自动恢复时间桶视图 |
| 收窄成窄栏 | 自动退出，回到核心渲染 |

## 设计约束与取舍

- **不注入核心菜单**：实测核心“视图选项”菜单（portal + 两阶段渲染）无法安全扩展——注入会导致菜单空/闪没；故采用独立入口 + 自绘弹层（体验等价，但绝不破坏核心）。
- 入口按钮只在核心 `headerActions` **尾部追加**（title-regenerate 同款的“追加最末”安全模式）。
- 激活 = 接管整节（隐藏核心 header+listArea、挂自绘界面）；关闭 = 原样恢复，核心状态不被改动。
- 列表数据不爬 DOM：全部由 sessions/workspaces 服务快照推导；任何异常 try/catch 兜底。
- 无 React：纯 DOM + `--dsw-*` 令牌；文案跟随 locale（zh/en）；1s reconcile 观察器负责挂入口、持久化自动重进、接管重挂与窄栏退出。

## 安装

```bash
dsh plugin --profile web add dsh-session-time-bucket   # 或 add ./dsh-session-time-bucket（本地活链接）
```

仓库统一安装模型（聚合伞包）见根 `README.md`：根 `package.json.dependencies` + 根 `cordis.patch.yml` 各一行，profile `devDependencies` `link:` 后 `dsh plugin --profile web install`。外部 client bundle 原样伺服：改 `src/client.js` 后**刷新页面**即可（`pnpm run dev:web` 时走 HMR）。
