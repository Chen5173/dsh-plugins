# 验收清单 — dsh-hindsight-model

逻辑层（`.env` 行级 merge、启动日志取最后一组、冲突源计算、生效判据、净化 env 构造、启停参数生成、进程身份校验、四层读取、备份/原子写/回滚、保存校验、DSH 侧读取与凭据不回传、HKCU 导出后删除、6 个端点的契约与脱敏、面板四层渲染与三态字段、守护进程区块与二次确认门、降级渲染）由 `test/bundle.test.mjs`（**89 条**）自动覆盖。标 `[B]` 的必须在真实 GUI 人眼/手测。

架构重点：**插件不启停守护进程**（只给一条净化过环境的可复制重启命令 + 验证按钮）；**写入是行级 read-modify-write**（绝不调 `profile create`，它会整体重写）；**生效判据是「文件三件套 vs 进程实际读到的三件套」**，时序关系只作佐证。

前置：本插件由管理器面板安装（`dsh-plugin-manager` →「本地插件」里启用 `hindsight-model`）。宿主半改动需重启 `dsh web`；客户端半改动刷新页面即可。

- [x] 11.1 `[B]` **未运行时会自动拉起**：开关默认开、守护进程处于停止状态 → 开启一个新会话 → 会话**立刻可用不被阻塞**，面板出现「正在后台冷启动（约 44–73s）」；约 1 分钟后变为运行中，且显示「上次自动启动：已启动」；**无窗口**
  > 2026-09-14 真机确认（宿主 00:04:12 起 → 00:04:39 会话触发 → 00:04:41 守护进程起来 → 00:05:19 冷启动完成）：`origin=auto`、`triggers=3`、`hostEvents=subscription-ok`、`health=healthy`、`applied=consistent`，**进程链上没有 `conhost`**。「正在后台冷启动」文案与「会话不阻塞」为构造保证（`ensureDaemon` 立即返回、启动在 `.then` 里跑），未逐帧目击。
