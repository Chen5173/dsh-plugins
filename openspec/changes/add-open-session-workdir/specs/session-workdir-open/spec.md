## Purpose

让用户从当前会话一键把该会话绑定的工作目录交给宿主机器的文件管理器打开，并让打开结果（成功、失败、目录已不存在）以可观察的方式反馈回来。

## ADDED Requirements

### Requirement: 会话视图提供打开工作目录的入口

系统 SHALL 在会话视图的头部动作条中提供一枚「打开工作目录」入口，作用于**当前选中的会话**。该入口 MUST 只在同时满足两个条件时出现：当前会话记录了非空的工作目录，且宿主机器报告自己能把路径交给桌面程序。入口 MUST NOT 影响会话的选中状态。

#### Scenario: 会话有工作目录且宿主可打开时出现入口

- **WHEN** 用户选中一个记录了非空工作目录的会话，且宿主报告可以打开原生路径
- **THEN** 头部动作条出现「打开工作目录」入口

#### Scenario: 宿主没有桌面时隐藏入口

- **WHEN** 宿主运行在无桌面环境（例如 headless Linux 容器）并报告无法打开原生路径
- **THEN** 该入口不出现在界面上，而不是出现后点击报错

#### Scenario: 会话未记录工作目录时隐藏入口

- **WHEN** 用户选中的会话没有记录工作目录（空路径或无目录归档下的会话）
- **THEN** 该入口不出现

#### Scenario: 入口跟随当前会话切换

- **WHEN** 用户从会话 A 切换到会话 B
- **THEN** 该入口指向的目录随之变为会话 B 的工作目录，无需刷新页面

### Requirement: 触发入口打开该会话的工作目录

系统 SHALL 在当前会话记录的工作目录上，把该目录**原样**（绝对路径，不做二次拼接或改写）交给宿主机器的默认程序打开；在 Windows 上这意味着资源管理器打开到该目录**内部**并展示其内容，在其它桌面系统上交给各自的默认文件管理器。

#### Scenario: Windows 上打开到目录内部

- **WHEN** 用户在 Windows 宿主上对一个工作目录存在的会话触发该入口
- **THEN** 资源管理器打开该目录并显示其中的文件与子目录，而不是打开其父目录并高亮该目录

#### Scenario: 非 Windows 桌面交给系统默认程序

- **WHEN** 用户在 macOS 或带桌面的 Linux 宿主上触发该入口
- **THEN** 目录由该系统的默认文件管理器打开，行为与 Windows 一致（打开到目录内部）

#### Scenario: 路径原样传递

- **WHEN** 会话记录的工作目录带有空格、中文、或 Windows 反斜杠分隔符
- **THEN** 打开的仍是该目录本身，路径不被拆断、不被二次解析为相对路径

#### Scenario: 连续触发各自生效

- **WHEN** 用户连续多次触发该入口
- **THEN** 每次触发都独立发起一次打开请求，前一次的成败 MUST NOT 让后续点击失效或卡在禁用态

### Requirement: 打开结果必须给出可观察反馈

系统 SHALL 对每一次触发给出反馈：成功时给出轻量确认；失败时给出说明原因的可读提示，且提示中 MUST 包含目标目录的路径本身，让用户无需切换界面即可判断是哪一个目录出了问题。进行中的请求 MUST 有可见的进行状态，且 MUST 有超时上限，不允许无限期停留在进行中。

#### Scenario: 打开成功

- **WHEN** 宿主确认已把目录交给桌面程序
- **THEN** 界面给出一次轻量成功确认，随后自动消失

#### Scenario: 目录已被删除或移动

- **WHEN** 会话记录的工作目录在宿主上已不存在或已不可访问
- **THEN** 界面给出失败提示，说明该目录当前无法访问（可能已被删除或移动），并显示该目录的路径

#### Scenario: 宿主的打开动作失败

- **WHEN** 宿主接受了请求但打开命令本身报错
- **THEN** 界面给出失败提示并携带宿主返回的原因文本，会话本身不受影响

#### Scenario: 请求长时间无响应

- **WHEN** 打开请求在超时上限内没有任何响应
- **THEN** 界面把该次触发判为失败并给出提示，入口恢复为可再次触发

### Requirement: 失败时目录路径仍可获取

系统 SHALL 在反馈中提供复制该会话工作目录绝对路径的手段，使用户在无法（或不想）在宿主上打开文件管理器时——尤其是浏览器与宿主不同机的远程访问场景——仍能把路径取走。提示 MUST 说明目录是开在**宿主机器**上而非浏览器所在机器上。

#### Scenario: 从提示中复制路径

- **WHEN** 用户在失败提示中选择复制路径
- **THEN** 剪贴板得到该会话工作目录的完整绝对路径

#### Scenario: 远程访问时说明目录开在宿主上

- **WHEN** 用户通过浏览器访问另一台机器上的宿主并触发该入口
- **THEN** 反馈中说明资源管理器是在宿主机器上打开的；用户仍可通过复制路径拿到目录位置

### Requirement: 入口文案跟随客户端语言

系统 SHALL 让入口及其反馈文案跟随客户端当前激活语言（至少中文与英文），并在语言切换后于下次渲染时生效。

#### Scenario: 中文界面

- **WHEN** 客户端语言为中文
- **THEN** 入口标题与反馈提示以中文呈现

#### Scenario: 切换到英文

- **WHEN** 用户在客户端把语言切换为英文后再次查看该入口
- **THEN** 入口标题与反馈提示以英文呈现

### Requirement: 触发入口不改变会话状态

系统 SHALL 保证触发该入口是一个只读观察动作：MUST NOT 切换当前会话、MUST NOT 重载页面、MUST NOT 向会话记录写入任何内容、MUST NOT 改变会话的运行状态或模型上下文。

#### Scenario: 打开目录后会话保持原样

- **WHEN** 用户在会话 A 上触发该入口并成功打开目录
- **THEN** 会话 A 仍是当前会话，对话内容、滚动位置与运行状态均无变化
